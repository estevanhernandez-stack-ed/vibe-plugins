## Verdict

Opus 5.5 collapses the split the tiering RFC was built on. The June era had a scarce judgment model and an abundant bulk model. Now one persistent model does both: Anthropic says medium effort matches Opus 5 at high, it is priced at $4/$20, and it will not retire before 2027-09-22. That changes the economics of the model-window play: this is an arrival that isn't a window, and the spec-bank's "executable from paper" backlog can now run at close to judgment quality.

The real risk isn't missing out on capability, it's **breaking changes**, and they land on the estate's API callers and on vibe-prompt's detectors.

## Capability facts that matter here

- **ID** `claude-opus-5-5` (Bedrock: `anthropic.claude-opus-5-5`). **1M context** at standard rates, 128K max output (300K via batch beta). Knowledge cutoff June 2026.
- **Price** $4/$20. Cache reads at 0.05x base ($0.20/MTok), half the usual ratio. Batch $2/$10.
- **Default effort is `medium`**, where every other model defaults to `high`. Anthropic's guidance: re-run effort sweeps, and keep xhigh/max for measured gains.
- **Breaking changes (400s):** `thinking: disabled` and `budget_tokens` (adaptive thinking is always on), forced `tool_choice` (`any` / `tool`), and `computer_20251124` on the Claude API. Responses may start with thinking blocks, so read blocks by type, not by position.
- **Thinking blocks are bound to the model and to the transcript prefix.** Editing earlier context and replaying a block returns a 400 for new accounts. Keep conversations append-only.
- **Claude Code:** requires **v2.1.280+**. Effort is set per model via `modelSettings['claude-opus-5-5'].effortLevel`. Requests flagged as cybersecurity work silently re-run on **Opus 4.8** unless `switchModelsOnFlag: false`.
- **Coming:** Sonnet 5.5 and Haiku 5.5 "in the coming weeks" (no date). **Retirement floors:** Sonnet 4.5 on **2026-09-29** (one week out), Haiku 4.5 on 2026-10-15, Opus 4.5 on 2026-11-24.

Sources: platform.claude.com model overview, the what's-new and migration guides, pricing, effort and deprecations pages; code.claude.com model-config; anthropic.com/claude-opus-5-5. The system card PDF was too large to fetch, so safety findings are not covered.
